05 — Projects

Selected work.

Speech AI Sep — Oct 2026

DikteYar — Offline Persian Speech Dictation for Windows

A Windows dictation tool that turns Persian speech into text in any program with one global hotkey — fully offline on the user's machine, with the live transcription beside the cursor. Built on an offline speech-recognition model (Shenava-Koochik, 114M parameters, via sherpa-onnx) running in real time on CPU, with voice punctuation commands, spoken-number to digit conversion, and stability work that cut the final word error rate from 34.1% to 30% in real-speech tests.

GitHub

Speech AI Sep 2026

ParSiGo — Offline Persian Text-to-Speech with Voice Cloning

A Persian text-to-speech tool that turns any text into natural speech offline on CPU and clones a new voice from a few seconds of reference audio. The model was optimized and exported to ONNX Runtime to run without PyTorch — cutting dependencies from ~1.2 GB to ~200 MB with output quality identical to the original engine — behind a Persian RTL interface with phoneme editing, built-in and user-uploaded voices, and long-text support. Model package and demo published on Hugging Face, and the project has 180+ stars on GitHub.

GitHub

Live Product Sep 2025 — Oct 2026

PelakGuard — Real-Time License Plate Detection, Masking & Reading

A live product that protects car owners' privacy when they publish vehicle ads: upload a photo, the plate is detected and masked (blur, redaction box, or custom logo), and the protected image is ready in seconds. Detection and recognition run on my own lightweight models — trained on a Persian plate dataset and optimized for real-time use — with four engines for standard, angled/rotated, OCR (Persian/English/Arabic) and hybrid cases, an interactive box editor, and a full Persian/English interface.

Live product — pelakgard.ir

LLM / RAG Jul — Nov 2025

DocQAI — Local Question-Answering over Persian Pharmaceutical References

A question-answering assistant for Persian pharmacy reference content: ask about a drug in natural Persian — indications, dosage, brands, side effects — and get answers grounded in the source text with citations, running entirely locally so sensitive material never leaves the machine. Includes the full RAG pipeline (ingestion, chunking, Qwen3 embeddings via Ollama, semantic retrieval), a bilingual Persian/English interface, chat sessions, and a documents dashboard.
